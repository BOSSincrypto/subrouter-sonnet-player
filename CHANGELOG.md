# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-08-14

### Added
- Initial release of Sonnet Player
- ExoPlayer integration with hardware acceleration
- Picture-in-Picture mode support (Android 8+)
- Gesture controls (swipe, double-tap)
- Playback speed control (0.25x to 2.0x)
- Multiple display modes (Fit, Fill, Crop, Stretch)
- Local video file scanning
- URL streaming support (HTTP, HTTPS, RTSP)
- Room database for playback history
- Settings with persistent preferences
- Material Design 3 UI

### Performance
- < 10ms play/pause latency
- < 50ms seeking latency
- 300MB video cache
- 60fps UI updates
